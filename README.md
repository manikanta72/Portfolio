# Portfolio Website

This is my personal portfolio website created to showcase my skills, projects, and professional profile.

The website highlights important information about my background, experience, and key projects, helping recruiters and visitors quickly understand my capabilities.

## Features
- Clean and modern layout
- Responsive design
- Sections for About, Projects, Skills, and Contact
- Direct links to GitHub and LinkedIn

## Tech Stack
- HTML
- CSS
- JavaScript

## Purpose
This project demonstrates my frontend web development skills as well as my ability to structure and present my professional profile on the web. It serves as a central place to showcase my work to recruiters and collaborators.
